为什么我选择纯静态 HTML 搭建个人博客

写博客最大的阻力往往不是“没东西写”，而是“每次写之前要先折腾构建工具、依赖升级或主题报错”。纯静态 HTML + CSS + 原生 JS 把复杂度降到最低，打开编辑器就能写。

以后怎么加新文章？

直接在 posts/ 目录下复制一篇现有的文章 HTML 文件改名，修改标题、时间和正文，再去 index.html 的时间线列表里加一条 <li> 链接即可。
